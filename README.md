# Grail backend

API for The Grail photo-booth product. Issues licenses, manages users, and handles subscriptions for the [Grail frontend](https://github.com/painbot-coin/grail_frontend).

## What is in here

- FastAPI app (`app/main.py`)
- User and license models, CRUD, and JWT helpers
- Subscription routes
- Password hashing

## Stack

Python, FastAPI, JWT, SQL
